EEG Monitor · 鸿蒙脑电监测应用2026.06 — 2026.10 · 独立开发 · 端到端

鸿蒙

基于 HarmonyOS API 12 的脑电实时监测应用：BLE 5.0 对接 TGAM 脑电传感器，实时绘制脑波、识别情绪、完成意图分类。

  • 打通 GATT 全流程，解决 MTU 协商、JSON 分片拼接、断线重连与重订阅等底层难点，保障数据稳定传输。

  • 以 Service / Detector / Store / Renderer / UI 五层架构驱动 30fps 实时渲染，同一份数据同时驱动波形、频谱、仪表与雷达图。

智教棱镜 EduPrism · 师范生教学能力诊断平台2026.06 — 2026.10 · 后端开发 + 知识图谱

后端

面向师范生的教学能力智能诊断与成长平台，以教育能力知识图谱为约束底座，由教案、课件、岗位、竞赛、证书等专业智能体协同完成材料诊断与训练生成。

  • 基于 Flask + Neo4j + MySQL 搭建分层后端，交付 56 个接口、20+ 个页面。

  • 编排 6 个专业智能体协同完成诊断与训练生成，输出统一契约并沉淀为成长档案。
  • 以 Docker Compose 实现一键部署与图谱自动初始化。

03

「大事件」新闻资讯管理平台2026.03 — 2026.06 · 全栈开发 · 独立完成

全栈

面向内容管理场景的全栈 Web 应用：用户注册登录、文章发布与管理、分类管理、富文本编辑、图片云存储，前后端分离。

  • 独立设计 user / category / article 三张核心表并建立外键关联，支撑用户、分类、内容三大模块。
  • 基于 Spring Boot 3 搭建 Controller / Service / Mapper / POJO 分层，交付 19 个 RESTful 接口；MyBatis XML 动态 SQL + PageHelper 实现多条件分页。
  • 实现 JWT + Redis 双重认证，改密后旧 Token 主动失效；封装全局异常处理与自定义状态校验注解。
  • 前端 Vue 3 Composition API 开发 7 个页面，Pinia 持久化登录态，Axios 拦截器统一注入 Token 与处理 401。
